# HeyGen + HyperFrames 生产检查表

## 生成前

- [ ] 口播文案有完整开头、主体、结尾。
- [ ] 确认是母版、完整成片，还是只做封面/文案。
- [ ] 确认视频画幅和封面入口比例没有混用。
- [ ] 盘点截图、图表、产品界面和 B-roll 的来源。
- [ ] 确认数字人、声音和语言。

## HeyGen

- [ ] 只提交一次。
- [ ] 保存真实视频 ID 和 completed 状态。
- [ ] 输出带字幕 MP4、无字幕 MP4、SRT（任务需要完整母版时）。
- [ ] 检查首句、尾句、嘴型、字幕遮挡、分辨率、帧率、音频。

## HyperFrames

- [ ] 读取 hyperframes 入口与对应 workflow/core/animation/creative/media/cli Skill。
- [ ] 先写时间轴/分镜，再写或改 HTML。
- [ ] 数字人仍然是叙事主体，截图只解释正在讲的内容。
- [ ] 首 3 秒不被封面或标题压住。
- [ ] 字幕不重复、不乱码、不压脸、不压截图关键区域。
- [ ] 没有无意义卡点、过重特效或机构化包装。
- [ ] lint、check、runtime、layout、contrast 和完整渲染通过。

## 封面

- [ ] 个人主页卡片：3:4，默认 1080×1440。
- [ ] 分享卡片：4:3，默认 1440×1080。
- [ ] 主标题、辅助文案和视频主题一致。
- [ ] 人物不挡字，字不挡脸；两个入口都检查裁切。
- [ ] 颜色和版式符合白底、深绿、亮蓝、荧光黄绿的 Sky 风格。

## 发布交付

- [ ] 标题短、直给，有主题关键词。
- [ ] 正文不增加视频没有讲过的事实。
- [ ] 标签 6–8 个，覆盖主题、行业、场景和人群。
- [ ] 交付路径、时长、分辨率、音轨、封面比例和质检结果写清楚。
- [ ] 未经明确确认，不执行平台发布。
