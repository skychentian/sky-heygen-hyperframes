# Sky 封面风格参考

本文件只描述视觉系统，不绑定任何个人文件、客户项目或历史文案。制作时结合当前口播主题和用户提供的人物参考。

## 比例先后

封面入口比例和视频画幅是两套概念：

| 资产 | 比例 | 默认像素 |
|---|---:|---:|
| 个人主页卡片 | 3:4 | 1080×1440 |
| 分享卡片 | 4:3 | 1440×1080 |
| 竖屏视频母版 | 9:16 | 1080×1920 |
| 横屏视频母版 | 16:9 | 1920×1080 |

只在用户明确要求平台特殊规格时修改像素，保留相应的展示比例和安全区。

## 版式骨架

### 3:4 个人主页卡片

- 画布上方留出标题呼吸区。
- 顶部左侧放主题胶囊标签。
- 主标题占左侧或上半区，最多三层文字。
- 人物放右下或下半区，保留头顶和肩部，不遮住主标题。
- 复杂装饰放在标题之外，不能落入人物脸部和文字区。

### 4:3 分享卡片

- 左侧约 55–60% 放主标题和辅助文案。
- 右侧约 35–40% 放 Sky 半身人物。
- 中间留出一段干净呼吸空间，避免人物和标题贴在一起。
- 底部可以放一条小号关键词线，但不放整段正文。

## 颜色与层级

建议从以下范围取色，具体由 image2 统一平衡：

- 背景：`#FFFFFF` 或 `#F7F9F7`
- 深森林绿：`#0B2B21`
- 亮蓝：`#1E57F5`
- 荧光黄绿：`#B9FF16` 或相近色
- 线路灰绿：`#6E8B7D`
- 网格：低对比度浅灰，不要让网格成为主体

默认文字层级：

1. 主题关键词：深绿或亮蓝的大字。
2. 结论/动作词：深绿字配荧光黄绿色高亮条。
3. 辅助说明：深绿小字，一行以内。
4. 顶部胶囊：白字，短标签，配小型播放图标。

## Image2 Prompt 约束

Prompt 必须明确写出：

- 具体比例和目标像素。
- 文字必须逐字准确、不能增加无意义文字。
- 左文右人的构图和人物安全区。
- 轻网格、线路节点、白底、深绿/亮蓝/荧光绿的风格。
- 不要深色大色块、近距离大脸、乱码、平台 UI、二维码和虚构数据。

Image2 返回后仍需做尺寸校正和图像预览。生成模型的原生尺寸不等于平台交付尺寸。
