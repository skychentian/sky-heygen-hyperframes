# Example Task Shapes

These examples are intentionally generic and contain no private assets.

## Mother Only

```text
用已配置的 HeyGen 数字人生成这段中文口播。只输出带字幕 MP4、无字幕 MP4 和 SRT，先不要调用 HyperFrames，也不要发布。
```

## Full Video And Covers

```text
把已确认的 HeyGen 母版用 Sky 风格做成 HyperFrames 成片，再用 image2 输出 3:4 个人主页卡片和 4:3 分享卡片，并给出标题、正文和标签。
```

## Cover And Copy Only

```text
不要重新生成数字人，只根据现有成片和主题制作两种入口封面，检查裁切、人物和文字，然后整理发布文案。
```
